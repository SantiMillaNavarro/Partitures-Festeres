Política de privacitat – Partitures Festeres

Partitures Festeres és una aplicació Android per organitzar, visualitzar, anotar i gestionar partitures musicals, així com utilitzar eines musicals com l’afinador, el metrònom, Dictat Musical i Dictat Marina.

La versió actual està dissenyada perquè les dades de l’usuari es processen principalment de manera local en el dispositiu.

1. Comptes i dades personals

L’aplicació no requereix crear cap compte, iniciar sessió ni proporcionar dades personals per poder utilitzar-la.

2. Ús del micròfon

L’aplicació sol·licita permís per accedir al micròfon únicament quan l’usuari utilitza funcions que necessiten analitzar so, com ara:

  • l’afinador;
  • Dictat Musical;
  • Dictat Marina.

L’àudio captat es processa localment en el dispositiu per estimar freqüències i notes musicals. L’àudio no s’envia a servidors externs, no es conserva com a enregistrament d’àudio i no es comparteix amb tercers.

L’usuari pot denegar o revocar el permís de micròfon des dels ajustos d’Android. Les funcions que no necessiten micròfon continuaran disponibles.

3. Partitures, arxius i dades de la biblioteca

Els PDF, carpetes, repertoris, favorits, recents, anotacions, ajustos i altres dades de la biblioteca es gestionen localment en el dispositiu o en ubicacions d’emmagatzematge seleccionades expressament per l’usuari.

Partitures Festeres no envia aquests documents ni el seu contingut a servidors propis o de tercers.

4. Imatges generades i funció de compartir

Algunes funcions poden generar una imatge, per exemple un pentagrama creat amb Dictat Musical o Dictat Marina. Aquesta imatge només es guarda o es comparteix quan l’usuari ho demana expressament.

Si l’usuari selecciona una aplicació externa mitjançant el menú de compartir d’Android, el tractament posterior de la imatge correspon a l’aplicació externa seleccionada.

5. Publicitat, analítica i seguiment

Partitures Festeres no inclou publicitat, no utilitza plataformes d’analítica de tercers i no realitza seguiment de l’activitat de l’usuari amb finalitats publicitàries o comercials.

6. Connexió a Internet

La versió actual de l’aplicació no sol·licita permís d’accés a Internet. Les funcions principals funcionen localment.

7. Compartició de dades amb tercers

Partitures Festeres no ven, cedeix ni comparteix dades personals amb tercers. Només es comparteix contingut quan l’usuari inicia voluntàriament una acció de compartir mitjançant les eines estàndard d’Android.

8. Conservació i eliminació de dades

Com que l’aplicació no utilitza comptes ni emmagatzematge en servidors propis, no existeix un perfil remot de l’usuari que calga eliminar.

Les dades locals de l’aplicació es conserven al dispositiu fins que l’usuari les elimina, elimina els arxius corresponents o desinstal·la l’aplicació. Les imatges exportades es conservaran a la ubicació triada per l’usuari fins que aquest les elimine.

9. Menors

L’aplicació no està dissenyada específicament per a menors ni recull deliberadament informació personal de menors.

10. Seguretat

Les dades de funcionament de l’aplicació es mantenen principalment al dispositiu. La protecció física del dispositiu i l’accés a les seues dades depenen també de les mesures de seguretat configurades per l’usuari en Android.

11. Canvis en aquesta política

Aquesta política pot actualitzar-se si s’incorporen noves funcions que modifiquen el tractament de dades. La data d’última actualització apareixerà al principi d’aquesta pàgina.

12. Contacte de privacitat

Per a consultes relacionades amb la privacitat o el funcionament de Partitures Festeres, es pot utilitzar el correu de suport publicat a la fitxa de Google Play o el repositori públic del projecte:

https://github.com/santimillanavarro/Partitures-Festeres

Privacy Policy – Partitures Festeres

Partitures Festeres is an Android application for organizing, viewing, annotating and managing sheet music, as well as using musical tools such as a tuner, metronome, Dictat Musical and Dictat Marina.

The current version is designed so that user data is processed primarily and locally on the device.

1. Accounts and personal data

The application does not require users to create an account, sign in or provide personal information in order to use it.

2. Microphone use

The application requests microphone permission only when the user uses features that need to analyze sound, including:

  • the tuner;
  • Dictat Musical;
  • Dictat Marina.

Captured audio is processed locally on the device to estimate frequencies and musical notes. Audio is not sent to external servers, is not retained as an audio recording and is not shared with third parties.

Users may deny or revoke microphone permission in Android settings. Features that do not require microphone access will remain available.

3. Sheet music, files and library data

PDF files, folders, repertoires, favorites, recent items, annotations, settings and other library data are handled locally on the device or in storage locations explicitly selected by the user.

Partitures Festeres does not send these documents or their contents to first-party or third-party servers.

4. Generated images and sharing

Some features may generate an image, for example a staff created with Dictat Musical or Dictat Marina. Such images are only saved or shared when the user explicitly requests it.

If the user selects an external application through Android's standard sharing interface, any subsequent processing of that image is handled by the selected third-party application.

5. Advertising, analytics and tracking

Partitures Festeres does not contain advertising, does not use third-party analytics platforms and does not track user activity for advertising or commercial purposes.

6. Internet access

The current version of the application does not request Internet access permission. Its main features operate locally on the device.

7. Sharing data with third parties

Partitures Festeres does not sell, transfer or share personal data with third parties. Content is only shared when the user voluntarily starts a sharing action using Android's standard sharing tools.

8. Data retention and deletion

Because the application does not use user accounts or first-party server storage, there is no remote user profile that needs to be deleted.

Local application data remains on the device until the user deletes it, removes the corresponding files or uninstalls the application. Exported images remain in the location selected by the user until the user deletes them.

9. Children

The application is not specifically designed for children and does not knowingly collect personal information from children.

10. Security

Application data is primarily stored on the user's device. Physical device security and access to device data also depend on the Android security measures configured by the user.

11. Changes to this policy

This policy may be updated if new features change how data is handled. The latest update date will be shown at the top of this page.

12. Privacy contact

For privacy or support questions regarding Partitures Festeres, users may contact the support address shown on the Google Play listing or use the public project repository:

https://github.com/santimillanavarro/Partitures-Festeres
