# User guide — Partitures Festeres

[Valencià](GUIA_US_va.md) · [Español](GUIA_US_es.md) · [English]

This guide explains the main features of **Partitures Festeres** and how to use them during rehearsals, performances and travel.

> Screenshots were taken from a recent version of the application. Some wording or visual details may differ slightly between versions.


## 1. First setup

When opening the application for the first time, select the **root folder** where your scores are stored.

The library is built from the device's real folder structure. Each subfolder automatically appears as a library category, allowing you to keep the same organisation you already use for your files.

The root folder can later be changed from **Settings**.

## 2. Library

The **Library** is the main access point for your scores.

![Library](images/biblioteca.jpg)

From here you can:

- browse score folders;
- search the whole library;
- open a score;
- refresh the library after adding, removing or reorganising files.

Folders are detected dynamically, so categories do not need to be recreated inside the app.

## 3. Repertoires

**Repertoires** let you prepare custom score lists for a performance, concert, parade, procession or any other event.

![Repertoires](images/repertoris.jpg)

You can:

- create multiple repertoires;
- add or remove scores;
- change score order;
- duplicate or rename a repertoire;
- start a performance and move through the scores in the selected order.

## 4. Recent

The **Recent** section shows the scores you opened most recently, providing quick access without searching the library again.

![Recent](images/recents.svg)

## 5. Favourites

Frequently used scores can be marked as **Favourites** for quick access.

![Favourites](images/favorits.svg)

## 6. Scan and import

Use the **+** button to add new scores.

![Scan and import](images/escanejar_importar.svg)

You can:

- **Scan score**: digitise paper pages using the camera.
- **Import PDF**: add an existing PDF file.

Before saving, you can name the score, choose its destination folder and optionally add it to a repertoire.

## 7. Score viewer

The score viewer is designed to use as much screen space as possible.

Portrait and landscape scores use the same viewer behaviour: simply rotate the tablet and the interface adapts.

Viewer options in **Settings** include:

- menu auto-hide time;
- showing the work title when changing scores;
- remembering zoom for each score;
- keeping the screen awake;
- allowing rotation inside the viewer.

## 8. Musical tools

The **Tools** section includes utilities for rehearsals and performances.

### Tuner

![Tuner](images/afinador.svg)

Uses the device microphone to show pitch deviation from the nearest note. The tuning reference can be adjusted.

### Metronome

![Metronome](images/metronom.svg)

Lets you choose tempo and time signature and start a regular pulse.

### Reference note

![Reference note](images/nota_referencia.svg)

Generates a continuous reference note from the device. You can select note, octave and reference frequency, with shortcuts for common notes.

## 9. Settings, backup and language

![Settings](images/ajustos.svg)

From **Settings** you can:

- switch between Valencian and Spanish;
- select a new root folder;
- create a backup;
- restore a previous backup;
- configure viewer behaviour.

Backups preserve app data such as repertoires, favourites, recent items, annotations, zoom and settings, but do not duplicate PDF files.

## 10. Recommended workflow

Before a performance:

1. keep scores organised in folders;
2. create a dedicated repertoire;
3. arrange pieces in the expected order;
4. mark frequently used pieces as favourites;
5. periodically back up the app configuration.
